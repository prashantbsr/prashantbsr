### Dr. Prashant Sharma

Physician building software for hospitals. Founder of [Pensieve Labs](https://www.pensievelabs.org) — interoperability and clinical workflow tooling for Indian healthcare.

- Working on **Pensieve**, a web app for hospital staff, with an on-prem bridge agent for LIS / RIS-PACS / PIS / HIS / EHR / EMR / billing integrations.
- TypeScript across the stack — Node + Fastify on the kernel, React + Vite on the shell, single-binary Node agent on-prem.
- Hexagonal architecture, schema-first (Zod), `Result<T, E>` everywhere, no orphans.

#### Open source
